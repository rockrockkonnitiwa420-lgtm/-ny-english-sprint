NY English Sprint - iPhone PWA版

【できること】
- Level 1 超初級 / Level 2 初級 / Level 3 留学実践
- Listening / Shadowing / Speaking
- Airport / Homestay / School / Subway / Shopping / Restaurant / Emergency
- 35フレーズ以上
- 英語音声読み上げ
- 音声認識（対応ブラウザでは自動。使えない場合は手動完了ボタン）
- 学習記録を端末内に保存
- ニューヨーク出発日カウントダウン
- ホーム画面追加対応

【iPhoneで使うには】
このPWAはHTTPSで公開する必要があります。
無料なら GitHub Pages / Cloudflare Pages / Netlify などに、このフォルダ一式をアップロードしてください。

公開URLをSafariで開く
→ 共有ボタン
→「ホーム画面に追加」
→ NY English Sprint のアイコンから起動

※ 音声認識はiOS/Safariのバージョンや権限設定により利用可否が変わるため、
使えない場合でもShadowing/Speakingは「声に出して言えた」ボタンで進められます。
